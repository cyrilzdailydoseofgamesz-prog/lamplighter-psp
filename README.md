# Lamplighter of Willowmere (PSP / PPSSPP) v2

Build: push to GitHub -> Actions -> "Build PSP EBOOT" -> download artifact -> unzip -> open EBOOT.PBP in PPSSPP.
Controls: stick move | O run | L/R camera | X talk / advance

## Walkthrough (5 chapters)
1. Talk to Elder Maren, find 3 Glowshards, relight the Great Lantern.
2. Find Sera (south path). Go to Orla in Whisper Woods (north-west). Collect 5 Moonpetals.
3. Moonlake (west): Dorin needs 4 planks for the bridge. Cross to Mira. Touch stones Red, Blue, Gold.
4. Emberpeak (north-east): Kael wants an Ember Key. Get 3 iron ore (east trail), Brannoc forges it, return to Kael. Light 4 braziers, use the altar.
5. Return to the Great Lantern.

Side quests: Tobin's cap, Hilda's Sunberries (speed boost), Orla's fox cub. 8 hidden Wisps.
A gold beacon marks your current objective.
